Packed model test

Each creature as build.py writes it (left) and with KHR_draco_mesh_compression (right). This browser reads both, so the two should look the same here. The question is whether the Quest and the Android phone can read the Draco one. The meshopt (EXT_meshopt_compression) and 16-bit (KHR_mesh_quantization) copies have both crashed QRay on the Quest (2026-11-16): scan those only on a phone.

  1. Open one code at a time: QRay reads every code it can see, and opening one closes the others.
  2. In QRay, scan a control code first. It is the model exactly as built: if it does not appear, the device is not reaching this page's files, and the test says nothing yet.
  3. Then scan the same creature's Draco code. It appears and walks: the device reads Draco. Nothing, or a crash: it does not.
